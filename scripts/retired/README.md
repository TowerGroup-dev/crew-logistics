# Retired: Excel import

These scripts read the "2026_ Crew Schedules (Master).xlsm" workbook into
`src/lib/crew-schedule-data.ts`. The 2026 schedule was read once (last run on
the 20 Nov 2026 workbook) and that reading is final.

They are kept for reference only and are not used any more. All changes,
for 2026 and every year after, are made in the app and shared through the
server. See `docs/working-with-data.md`.

Do not run them: re-running would replace the 2026 starting data.
